## ✨ About This Lab

Welcome! This repository is a complete record of experiments for the **Statistics & Machine Learning Laboratory** — a course designed to build a rock-solid foundation in statistical reasoning before layering on modern machine learning techniques.

Each experiment builds on the last: starting with *describing* data, moving through *inferring* truths from it, and ending with *building, evaluating, and explaining* full-fledged ML models. Two capstone-style case studies tie everything together into real-world problem solving.

> 🎯 **Goal:** Not just to run code, but to *understand the "why"* behind every statistical and machine learning technique.

## 🧪 Experiment Index

### 🔹 Basic Experiments

| # | Experiment | Focus Area |
|:-:|---|---|
| 1 | **Apply Descriptive Statistics and Data Visualization Techniques for Exploratory Data Analysis** | Mean, median, variance, plots, distributions |
| 2 | **Implement Correlation Analysis, Distance Measures, and Data Preprocessing Techniques** | Pearson/Spearman correlation, Euclidean/Manhattan distance, scaling & encoding |
| 3 | **Perform Statistical Inference, Estimation, and Hypothesis Testing on Real-World Datasets** | Point/interval estimation, t-tests, chi-square tests |
| 4 | **Implement Resampling Techniques and Confidence Interval Estimation for Statistical Decision Making** | Bootstrapping, cross-validation, CI construction |
| 5 | **Develop and Evaluate Regression Models using Statistical Performance Measures** | Linear/multiple regression, R², RMSE, MAE |
| 6 | **Build and Evaluate Classification Models using Supervised Learning Algorithms** | Logistic regression, KNN, decision trees, SVM |
| 7 | **Apply Clustering and Dimensionality Reduction Techniques for Pattern Discovery** | K-Means, hierarchical clustering, PCA |
| 8 | **Evaluate and Interpret Machine Learning Models using Validation and Explainability Techniques** | Confusion matrix, ROC-AUC, SHAP/LIME |

## 🚀 How to Use This Repo

1. **Clone the repository**
```bash
   git clone https://github.com/your-username/statistics-ml-lab.git
   cd statistics-ml-lab
```
2. **Set up your environment**
```bash
   pip install -r requirements.txt
```
3. **Navigate to any experiment folder** and open the notebook:
```bash
   jupyter notebook experiment-01-eda/experiment_01.ipynb
```
4. Run cells sequentially — each notebook contains the **aim, theory, code, output, and observations**.
